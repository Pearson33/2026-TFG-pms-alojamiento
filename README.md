# Aplicación web de gestión y reservas para alojamientos turísticos pequeños
 
Trabajo de Fin de Grado que desarrolla un sistema de gestión de alojamientos (PMS, *Property Management System*) con motor de reservas, pensado para alojamientos turísticos pequeños que hoy gestionan sus reservas de forma manual o repartida entre varias plataformas.
 
La aplicación permitirá gestionar las habitaciones y las reservas desde un único sitio, evitar reservas solapadas (*overbooking*), sincronizar la disponibilidad con plataformas de reserva externas mediante calendarios iCal y ofrecer a los huéspedes un motor de reservas propio.

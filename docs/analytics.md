# Análisis

Este documento describirá cómo se organiza la aplicación antes de programarla. 

- **Pantallas y navegación:** diagrama de navegación por rol y tabla de pantallas.
- **Entidades:** diagrama entidad-relación y explicación de las relaciones principales.
- **Permisos:** qué puede hacer y ver cada rol.
- **Arquitectura general:** bloques principales de la aplicación y cómo se comunican.
- **Elementos exigidos por la guía docente:**
  - Imágenes: fotos de las habitaciones.
  - Gráficos: panel de ocupación e ingresos.
  - Tecnología complementaria: sincronización de calendarios (iCal), correos y tareas programadas.
  - Algoritmo o consulta avanzada: cálculo de disponibilidad y control de reservas solapadas.

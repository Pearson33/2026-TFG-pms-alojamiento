# Funcionalidades

> **Pendiente — Fase 1.** Se completará después de la entrevista con la propietaria y se validará con ella.

Este documento definirá el alcance del proyecto: qué hace la aplicación, para quién y en qué versión. Recogerá:

- **Roles:** los tipos de usuario de la aplicación.
- **Funcionalidad básica, intermedia y avanzada:** lo que hace la aplicación en cada nivel, con una tabla por rol. Cada nivel corresponde a una iteración: básica (Fase 3, v0.1.0), intermedia (Fase 4, v0.2.0) y avanzada (Fase 5, v1.0.0).
- **Fuera de alcance:** funcionalidades descartadas o para un trabajo futuro.
